# NOVA AI Hub

**NOVA AI Hub** مساحة عمل عربية موحّدة لمهام الذكاء الاصطناعي. يوفر الإصدار الأول محادثة نصية، وتوليد صور، ورفع مرفقات.

> لا يتجاوز NOVA الحصص أو القيود. يعمل التبديل الاحتياطي فقط بين المفاتيح الشخصية التي حفظها صاحب الحساب، أو عب

## القدرات

| المجال | ما يقدمه NOVA |
| --- | --- |
| المحادثة | يرسل الطلب إلى NOVA Core أو مزوّد شخصي مهيأ، ويحفظ الرسائل ضمن سجل الحساب. |
| الصور | ينشئ صورة من وصف نصي عبر كتالوج نماذج الصور المتاح في بيئة المشروع. |
| المرفقات | يرفع ملفات الصور والمستندات والصوت إلى التخزين المهيأ ويحفظ البيانات الوصفية فقط في قاعدة البيانات. |
| الصوت | يحوّل المرفق الصوتي إلى نص ثم يضيفه إلى مساحة العمل؛ حد الملف في الواجهة هو 8 ميغابايت. |
| المزوّدات | يدعم NOVA Core وGroq وCerebras. لا يظهر المزوّد الشخصي جاهزاً إلا بعد حفظ مفتاحه في الخادم. |
| الشفافية | يعرض حالة المزوّد والنموذج. يقرأ رؤوس حدود Groq من آخر استجابة مصرح بها عند توافرها، ولا يخترع رصيداً عندما لا تتاح واجهة رسمية لقراءته. [1] |

## التشغيل المحلي

يتطلب المشروع **Node.js 22** و`pnpm`. انسخ إعدادات البيئة المناسبة لبيئتك، ثم ثبّت الحزم وشغّل خادم التطوير.

```bash
pnpm install
pnpm dev
```

يمكن التحقق من النوع والاختبارات قبل النشر بالأوامر التالية:

```bash
pnpm check
pnpm test
pnpm build
```

## متغيرات البيئة

تُحقن المتغيرات التالية تلقائياً في بيئة الاستضافة المدارة. لا تُحفظ القيم الحقيقية في Git، ولا يلزم إضافة مفاتيح Groq أو Cerebras هنا لأنها تُدخل من المستخدم عبر واجهة NOVA وتُشفّر في الخادم.

| المتغير | الاستخدام | مطلوب محلياً |
| --- | --- | --- |
| `DATABASE_URL` | اتصال MySQL/TiDB المستخدم للسجل والإعدادات والمرفقات. | نعم للميزات المستمرة. |
| `JWT_SECRET` | اشتقاق مفتاح التشفير لحفظ مفاتيح المزوّدات الشخصية باستخدام AES-256-GCM. | نعم عند حفظ مفاتيح. |
| `BUILT_IN_FORGE_API_URL` | بوابة خدمات النماذج والتخزين والصوت والصورة على الخادم. | توفره المنصة. |
| `BUILT_IN_FORGE_API_KEY` | مصادقة الخادم مع بوابة الخدمات المهيأة. | توفره المنصة. |
| `VITE_APP_ID` و`OAUTH_SERVER_URL` و`VITE_OAUTH_PORTAL_URL` | جلسة تسجيل الدخول وOAuth. | توفرها المنصة. |
| `VITE_FRONTEND_FORGE_API_URL` و`VITE_FRONTEND_FORGE_API_KEY` | تكاملات الواجهة المهيأة من المنصة. | توفرها المنصة. |

## سياسة المزوّدات

يحفظ NOVA مفتاح Groq أو Cerebras بعد تشفيره في قاعدة البيانات ولا يعيده إلى المتصفح. يجري فحص اختياري وخفيف للمزوّد عند حفظه.

توضح وثائق Groq أن معلومات الحدود المتبقية يمكن إرسالها في رؤوس HTTP، ولذلك يقرأ NOVA هذه الرؤوس من الاستجابة المصرح بها عند توافرها.

## بنية البيانات

| الجدول | الغرض |
| --- | --- |
| `user_preferences` | اللغة، المظهر، النموذج المفضّل، وخيارات التبديل المصرح به. |
| `provider_credentials` | مفتاح مشفّر ومزوّد ونموذج افتراضي لكل مستخدم. |
| `conversations` و`conversation_messages` | سجل مهام المحادثة والصورة والرسائل الناتجة. |
| `attachments` | بيانات الملف الوصفية ومفتاح التخزين ونتيجة التفريغ، دون تخزين بايتات الملف في قاعدة البيانات. |

## ملاحظات النشر

التطبيق مهيأ للعمل في بيئة Node.js مدارة. بعد التحقق من الاختبارات، أنشئ نقطة تحقق ثم انشر من لوحة إدارة المشروع.
